## Setup Instructions

Follow these steps to set up your environment and get started:

### 1. Install Python
If you don’t have Python installed, download and install it from [python.org](https://www.python.org/).

### 2. Set Up a Virtual Environment
A virtual environment helps keep your project dependencies isolated. Run the following commands:

```bash
# Create a virtual environment
python3 -m venv myenv

# Activate the virtual environment
# On macOS/Linux:
source myenv/bin/activate
# On Windows:
myenv\Scripts\activate
